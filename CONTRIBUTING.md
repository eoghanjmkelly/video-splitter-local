# Contributing

Thanks for your interest in contributing!

## Development setup

- Requirements: Node.js 18+
- Apps live in:
  - `video-merger-gui/`
  - `video-splitter-gui/`

Install and run (dev):

```bash
cd video-merger-gui && npm install && npm start
cd video-splitter-gui && npm install && npm start
```

## Commits and PRs

- Use conventional commits when possible (feat:, fix:, docs:, chore:, refactor:).
- For non-trivial changes, open an issue or draft PR for discussion first.
- Add/update docs and tests as appropriate.

## Linting/tests

- If/when linting/tests are added, run them before opening PRs.

## Security

- Do not include secrets in code or PRs. See `SECURITY.md` for reporting vulnerabilities.
